WalkThor 1.96.0

## Fixed
- **PS2 games start in ARMSX2.** WalkThor was opening ARMSX2's splash screen, which ignores the game it's given. It now opens ARMSX2's game screen directly. Emulators also get read access to your whole ROMs folder, for games in more than one file.
- **Cocoon's artwork.** WalkThor now reads an art folder however it's laid out: Cocoon's data folder, ES-DE's, or any other. It looks for a system folder somewhere above each picture, and a covers or screenshots folder (or a picture named "cover" inside a folder named after the game). Settings now says how many pictures it found, so a folder it can't make sense of is easy to spot.

## New
- **Download missing pictures.** In Settings → Guides → Games screen, Download gets covers and screenshots for games that have none. They come from the free libretro collection, and from Steam for PC games whose shortcut holds a Steam id. Nothing needs an account. Pictures are kept on this device, and your own folder's pictures always win. Switch games aren't in any free collection.
- **Apps on the games screen.** An Apps button opens your other apps, for when WalkThor is your home app.
