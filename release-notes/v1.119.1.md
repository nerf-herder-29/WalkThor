# WalkThor 1.119.1

## Joy-Con joining: better answers
- When joining Joy-Cons doesn't work, the Controllers screen now shows what the joining program got through: whether it made the controller, whether each Joy-Con is being read, and any error. Before, it could only say there was "no word from it".
- The joined controller now stays as long as either Joy-Con is still being read, instead of going as soon as one has a problem.
- WalkThor waits a little longer for the joined controller to appear.
