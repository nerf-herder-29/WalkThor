# WalkThor 1.116.0

## Louder sounds, clearer top screen
- Background music plays a quarter louder at each volume setting (Quiet, Medium and Loud).
- The navigation sounds (moving, changing tabs, picking and starting a game) are a quarter louder too.
- On the top screen, the time and battery and the button hints (A Play, Y Guide, X Options) now sit on dark pills in brighter white, so they stay readable over any picture.

## Apps open where you want
- When the Apps tab asks which screen to open an app on, two more choices settle it for good: "Always the top screen" and "Always the bottom screen". After that, apps open there straight away.
- To change it, or go back to being asked, use Settings › Screen › Open apps on (Ask, Top or Bottom).

## PokeDaisy updates from its new site
- PokeDaisy now puts its releases on pokedaisy.com instead of GitHub, and Updates follows it there. Updates finds the newest version on pokedaisy.com/releases and can download and install it as before. A PokeDaisy release page you set to its old GitHub page moves over by itself.
