WalkThor 1.37 comes back when a heavy game pushes it out.

## Fixed
- **WalkThor reopens itself if Android closes it mid-game.** Big games (heavy Switch games especially) can need so much memory while loading that Android closes other apps to make room, WalkThor included. Now, when Android does that while WalkThor is on the bottom screen during a game, WalkThor reopens there a few seconds later and hands the game its top priority back, as usual. It never reopens after you close it yourself, and stops after three tries in ten minutes so it can't loop.
- **Lighter on memory when a game starts.** WalkThor lets go of cached pages and covers as a new game launches, and whenever Android says memory is getting tight, so it's less likely to be closed in the first place.
- **Diagnostics says what happened.** ⋮ → About & licences → Diagnostics shows when Android last closed WalkThor and whether it reopened. If WalkThor ever crashes in a way it couldn't record before, that crash report is saved there too.
