WalkThor 1.92.10

## Changed
- **The tap that keeps the game in front is now sent as an ordinary touch.** In 1.92.9 the tap went through Android's accessibility service, and it didn't keep the game alive the way a real tap did. It now goes through AYN's system helper using Android's own touch command, which Android handles like a finger. It still lands on the very top edge of the game's screen, at the same times as before. When memory is critical, it falls back to the accessibility tap, because the touch command briefly starts a small program. For now the memory log notes every tap and how it was sent, so it's easy to see whether it worked.
