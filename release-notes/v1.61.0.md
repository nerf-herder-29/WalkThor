WalkThor 1.61.0 adds brightness, volume and the top screen's FPS to Now playing.

## New
- **Quick controls on Now playing** (what the drawer opens to during a game), above the game's marquee:
  - **Brightness** for the top screen, the bottom screen, or both. Pick which with Top screen / Bottom screen / Both. Changing the top screen's brightness needs Android's *Modify system settings* for WalkThor; the panel asks the first time.
  - The bottom screen uses AYN's own brightness setting if WalkThor is allowed to change it. Otherwise WalkThor dims the bottom screen itself, which can make it darker but not brighter than its own setting.
  - **Volume** (one for the device).
- **The top screen's FPS** under the tabs, read straight from the display driver with no screen capture, if the device allows it.
- Diagnostics shows what works on your device: whether WalkThor can change each screen's brightness, the brightness settings it found, and whether it can read the frame rate.
