WalkThor 1.92.5

## Fixed
- **WalkThor's memory-killer protection actually works now, and puts the game first.** The commands WalkThor sends through AYN's system helper to read and set how Android ranks apps for its memory killer came back with nothing at all. So for a long time, protecting WalkThor and your home app silently did nothing. The "put the game first" change in 1.92.4 never ran either, and the Ranks lines said "no processes found". The commands are rebuilt from plain parts the helper handles. During a game, the game's on-screen processes are set to rank 0 (in the Banana Native crashes Android had them at 101, which made the game the first thing closed), and WalkThor and your home app stay behind it at 50. If the helper isn't allowed to change a rank, the memory log now says so.
- The Ranks lines, and the check for apps restarting during a game, use the same rebuilt commands.

## New
- When WalkThor starts outside a game, the memory log notes which kinds of commands AYN's system helper passes through. This explains why some sections of game reports have always come back empty.
