WalkThor 1.72.1 handles games Cocoon starts from a shortcut.

## Fixed
- **Shortcut games no longer show the previous game.** Cocoon doesn't write games it starts from a shortcut (such as BananaNative games) to its launch log, so WalkThor kept showing the last game it had logged. Now, when the app in front on the top screen isn't the one Cocoon last launched, WalkThor goes by the app in front instead: it recognises the game from your ROMs folder or guides where it can, and otherwise asks what you're playing (and remembers your answer for next time).
- **BananaNative is recognised as an emulator**, for Windows games.
