WalkThor 1.63.3 tries AYN's own bottom-screen brightness again.

## Fixed
- **The bottom screen's brightness could fall back to dimming for good.** WalkThor checks once whether it may change AYN's bottom-screen brightness setting; if that check ran before you'd allowed *Modify system settings*, it failed and wasn't tried again. It now waits until the permission is allowed. When it works, the bottom slider changes the bottom screen's real brightness, in step with AYN's drawer.
- Diagnostics shows each brightness setting's current value, and why WalkThor couldn't change the bottom screen's, if it can't.
