WalkThor 1.92.8

## Fixed
- **Pausing your home app no longer leaves the game first in line for the memory killer.** When WalkThor pauses your home app, Android starts its own launcher on the bottom screen as the game loads, and again whenever the memory killer closes it. That launcher takes Android's "app in front" spot, which decides who is closed last. The game then drops behind the bottom screen's apps and is closed first. With the pause turned off, nothing started there, and the game outlasted everything else. Now, during a game, WalkThor checks which app Android has in front: right after pausing your home app, again whenever a home app comes up, and every few seconds. If it's a home app instead of the game, WalkThor taps the very top edge of the game's screen, the same way the controller lock does, which puts the game back in front. The memory log notes the first time each game needed it. Apps you open on the bottom screen yourself, WalkThor's own screens, and a controller locked to the bottom screen are left alone.
