WalkThor 1.50.2 reads your frontend's whole screen to recognise the game you pick.

## Changed
- **Recognise the game you pick reads the frontend's screen.** Some frontends (Cocoon among them) report only a background label like "custom wallpaper" as highlighted, with the game's name elsewhere on screen. WalkThor now reads all the text on your frontend's screen and, when an emulator starts, picks the game whose name appeared most recently and matches a game in your ROMs folder or one of your guides. Anything that doesn't match a game (menu labels, buttons, wallpaper names) is ignored. It only reads frontends and your home-screen app, never other apps, and keeps the text in memory only.
- **Clearer test readout.** With the performance check on, WalkThor shows what it read from your frontend's screen, which of your games it found there, and what it recognised at the last launch.
