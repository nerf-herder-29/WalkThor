WalkThor 1.29.1 simplifies Controls into a live view of the Thor's own buttons.

## Changed
- **Controls shows the Thor's buttons.** Instead of guessing each emulator's controller and mapping, which didn't always match your own emulator settings, Controls now draws the Thor's buttons (sticks, D-pad, face buttons, shoulders, Start and Select) and, with **Show presses** on, lights up whatever you press. The emulator layouts, the Layout picker and the mapping corrections are gone.
- **See what the Thor sends.** With Show presses on, the line at the bottom names the button and the code the Thor sent, for example "You pressed R1 · sent as BUTTON_R1". It now also catches controller buttons WalkThor didn't know about.
- **Sticks and D-pad.** Android doesn't share analog stick movement with accessibility services, and some controllers report the D-pad the same way as a stick, so these may not light up. The screen says so. Pressing a stick in (L3/R3) does light it.
