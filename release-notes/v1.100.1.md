WalkThor 1.100.1

## Fixed
- **Cocoon's artwork shows up.** Cocoon adds an edit marker to the end of each picture's name (`…__cocoon_edit_11_a6abfb9d…`), so the names never matched your games. WalkThor now leaves that part off. Your art folder is read again after this update.
- **Emulator folders aren't games.** Folders like "firmware" or "keys" in a system's ROMs folder no longer show up as games.
