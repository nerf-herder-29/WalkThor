WalkThor 1.49 knows your ROMs and can fetch their artwork.

## New
- **Your ROMs folder.** Link the folder that holds one folder per system (3ds, nds, gba, switch, psp, ps2, gc and so on) from ⋮ → *Link ROMs folder…*. WalkThor reads the game names, never the games themselves.
- **Pick the game you're playing.** Without Cocoon, *What are you playing?* now lists the games in your ROMs folder for the running emulator's systems (GameCube and Wii games for Dolphin, say), plus your guides, with your last picks first and a search box. Picking a game brings in its artwork and opens the matching guide if you have one. WalkThor also spots the game by itself if the emulator shows a name that matches one of your games.
- **Artwork scraping.** Add a ScreenScraper account and/or a SteamGridDB API key in ⋮ → *Scraper accounts*, then *Scrape artwork*. WalkThor fetches box art (ScreenScraper, by system and ROM name) and wide art and logos (SteamGridDB), and uses them on Now playing, the splash and behind the tabs. A game you pick that has no art yet is scraped on the spot.
- **Open when an emulator starts, with Cocoon too.** The setting now works with Cocoon linked: WalkThor opens whenever an emulator comes to the front, and Cocoon names the game and its art as usual.

## Fixed
- **WalkThor didn't always open when an emulator started**, especially the second time with the same emulator. Every time an emulator comes back to the front after another app, it now counts as a new game, and quick launches are no longer missed.

## Privacy
WalkThor now has internet access, used only for scraping: only when you've added an account and start a scrape (or pick an unscraped game), and it sends only the game's file name, system and your account details to that service. See PRIVACY.md.
