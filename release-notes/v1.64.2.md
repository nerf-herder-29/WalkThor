WalkThor 1.64.2 fixes the bottom screen's brightness slider.

## Fixed
- **The bottom screen stopped brightening or dimming in 1.64.1.** If the live brightness program couldn't start, every change waited for it for several seconds. It now starts fully detached, and if it still can't be reached, WalkThor stops waiting straight away and changes the brightness one step at a time (a little slower, but it works). Diagnostics shows which way the bottom slider is using.
