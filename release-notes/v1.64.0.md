WalkThor 1.64.0 changes the bottom screen's real brightness on the Thor.

## Improved
- **The bottom screen's brightness is real now, and stays in step with AYN's drawer.** Android only lets system apps change a second screen's brightness, so WalkThor goes through the system helper AYN builds into the Thor's firmware (the one behind its *Run Script as Root* feature and its own drawer), as AYN's drawer does. WalkThor uses it for brightness only, with commands made from numbers it works out itself.
  - If the helper isn't available (for example with the Thor's *Force SELinux* setting on), WalkThor dims the bottom screen as before. Diagnostics says which.
- About & licences lists HiddenApiBypass (LSPosed, Apache License 2.0), used to reach the helper.
