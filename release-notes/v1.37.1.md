WalkThor 1.37.1 comes back faster after a heavy game pushes it out.

## Changed
- **Reopens sooner.** When Android closes WalkThor to free memory during a game, it now reopens 2 seconds after Android lets it restart (down from 8).
- **More tries.** It reopens up to 5 times in 10 minutes (up from 3) before staying closed.

## Also in this release
If you skipped 1.37.0: WalkThor reopens itself on the bottom screen if Android closes it mid-game, frees memory when a game starts, and Diagnostics shows when this happened.
