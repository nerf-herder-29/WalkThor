## What's new

- **Tilt to look around.** With movement on the top screen, tilting the Thor shifts the game's picture one way and its logo the other, like looking through a window. However you usually hold it counts as level, so it only moves when you tilt it. It's off when *Movement on the top screen* is off, and the motion sensor is only read while the top screen is showing.
- **Any controller as the Thor's own.** Controllers › Other controllers: a Bluetooth or USB controller can now join the Thor's built-in controller the way Joy-Cons do, so every emulator already set up for the Thor just works with it, with no second player and nothing to remap. It joins by itself when it connects (switch that off if you'd rather join it by hand), its Home button is the Thor's Back button, and you can choose whether its face buttons go by letter (A is the Thor's A) or by where they sit. WalkThor reads each controller's buttons the same way Android does, so its sticks, triggers and D-pad land in the right places.
