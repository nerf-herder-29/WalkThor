WalkThor 1.92.9

## Fixed
- **Heavy games no longer get closed first while your home app is paused.** Pausing your home app makes Android start its own launcher on the bottom screen as the game loads. That launcher takes Android's "app in front" spot, which decides who the memory killer closes last, so the game was the first thing closed when memory ran out. A tap on the game's screen after it loads puts the game back in front: in five Banana Native sessions in a row with a tap, the game outlasted the squeeze that had closed it before. WalkThor now makes that tap itself, on the very top edge of the game's screen, a few times while the game loads (2, 8, 20 and 40 seconds after your home app is paused) and again whenever a home app comes up on the bottom screen during the game. The memory log notes it once per game. It's skipped when your controller is locked to the bottom screen, while you're typing in WalkThor, and for games set to use both screens.
