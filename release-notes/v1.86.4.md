WalkThor 1.86.4 helps stop the bottom screen flashing during heavy games, without costing you the game. Changes since 1.86.1:

## Fixed
- **Fewer crash loops on the bottom screen.** When a game suddenly needs a lot of memory, Android can close your home app and WalkThor, and they keep being closed as they start again, which is the white flashing on the bottom screen. WalkThor already ranked them just below the game for Android's memory killer, but WalkThor was often closed in the same burst, and while it was gone nothing kept the home app protected. Now WalkThor's small second process, Keeper, re-applies the protection once a second during games too. It needs Force SELinux off, as before.

## New
- **The game comes first.** When memory gets critical during a game (free memory under 1.5 GB, or Android's most serious memory warning), WalkThor stops protecting the bottom screen's apps and lets go of what it can, so Android closes those rather than your game. You might see a blink on the bottom screen at that moment. The protection comes back once memory has recovered for 20 seconds. The memory log notes each time.
- **The bottom screen goes dark instead of flashing white.** In those critical moments, WalkThor also turns the bottom screen's brightness right down, before Android starts closing things. It stays dark even if WalkThor itself is closed, then comes back to the brightness it had once memory has settled for 30 seconds, when the game closes, or when WalkThor starts again and no game is in front. It needs Force SELinux off.
- **Keeper's status in Diagnostics.** About & licences → Diagnostics → Memory during games shows whether Keeper is running, whether it can use AYN's system helper, and how it's ranking the bottom screen's apps. Lines starting "Keeper:" in the memory log show what it changed while WalkThor was closed.
