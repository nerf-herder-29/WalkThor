WalkThor 1.93.0

## Changed
- **WalkThor stands in as home while your home app is paused.** Until now, pausing your home app for a game made Android start its own launcher (Quickstep) on the bottom screen. That launcher took Android's "app in front" spot, which decides who the memory killer closes last, so heavy games were closed first. Now WalkThor's own home screen stands in: a plain black screen with the drawer over it as usual, using next to no memory. Android tells it the moment it gets the "app in front" spot, and it hands the spot straight back to the game with one tap on the very top edge of the game's screen, then checks that it worked. The memory log says when it got the spot, and whether handing it back worked. This home screen is only switched on while your home app is paused, so the rest of the time WalkThor isn't offered as a home app. If it can't be switched on, Android's launcher stands in as before.
