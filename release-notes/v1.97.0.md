WalkThor 1.97.0

## New
- **Settings across both screens.** With no game running, the top screen now explains the setting you're on: where it is, what it does, and how it's set now. Touch a setting, or move to it with the D-pad, to read about it. Before you pick one, the top screen shows the open section and what's in it.
- **Settings tabs look like the in-game tabs.** The sections now run along the top as tabs, each with a small icon over its name. A short line under the open one glides to whichever you pick. The settings themselves get the full width of the screen.
- Buttons pressed while the top screen has the controller now work Settings on the bottom screen too.
