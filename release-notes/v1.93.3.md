WalkThor 1.93.3

## Fixed
- **Game reports are saved again when the memory killer closes WalkThor along with the game.** With WalkThor's black screen standing in as home, Android's memory killer now often closes WalkThor in the same moment as the game. WalkThor then started again without knowing a game had just ended, put your home app back, and never saved a report, so Share game report kept sending an old one. WalkThor now remembers which game it paused your home app for. If it starts again and finds that game gone, it saves the report then.
