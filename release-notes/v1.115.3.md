# WalkThor 1.115.3

## Fixes
- If Android closes WalkThor to free memory during a game, WalkThor no longer covers the game with its top screen when it comes back. It now waits until it knows what's on the top screen, and stays out of the way while a game is there. The music waits too, so it can't start over the game.
- Background music now starts more reliably. Before, WalkThor's own tap sounds, or a game's sound still fading out as you came back, could make it think another app was playing music, and then it stayed silent. Now it only holds back for real music or video apps, and if one is playing it looks again a few times over the next several seconds.
