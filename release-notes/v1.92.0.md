WalkThor 1.92.0

## New
- **RAM saver mode.** During a game, when memory gets tight, the drawer now steps down instead of staying up or vanishing. It kicks in when free memory drops under 3 GB, or falls by 500 MB or more within 5 seconds (as when a game loads or changes scene). The bottom screen then shows only the time, battery and free memory, drawn on a plain screen that uses a few MB instead of the drawer's 50 or so. Once memory is above 3.3 GB and steady for 5 seconds, the drawer comes back where you were. A tap brings it back straight away, and saver mode then leaves you alone for 30 seconds. When memory is critical, the black cover still takes over as before. The memory log notes each time saver mode turns on or off, and why.
