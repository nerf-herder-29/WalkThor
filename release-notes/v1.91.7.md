WalkThor 1.91.7

## Fixed
- **WalkThor comes up sooner once a game has loaded.** While the bottom screen waits on black, WalkThor also waits for Android's memory pressure to settle. Some games keep swapping a little the whole time, so that wait could run past a minute even though memory had long stopped dropping. After 30 seconds the pressure check is now looser, and the longest wait is 90 seconds instead of 2½ minutes.
- **The controller lock holds while a game loads.** Android gives the controller to a screen whenever an app starts there, without any touch. When your stand-in home app started on the bottom screen during loading (WalkThor pausing your home app, or Android restarting it after the memory killer closed it), the controller left the game even though it was locked to the top screen. The lock now takes it back when an app comes up on the other screen, not only when you touch it.
