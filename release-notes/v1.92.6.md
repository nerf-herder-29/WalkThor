WalkThor 1.92.6

## Fixed
- **The Ranks lines in the memory log can be read now.** In 1.92.5 they found the game's and WalkThor's processes but couldn't read their ranks. Each rank is now read in the plainest way, and if that still fails, the line shows what came back.
- **The memory log shows when Keeper puts the game first.** Keeper, WalkThor's small helper process, sets the game's rank every few seconds during a game. The memory log now notes the first time it does that for each game process.
