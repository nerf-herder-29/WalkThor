WalkThor 1.25 adds step-by-step setup instructions inside the app.

## New
- **How to set up WalkThor.** It's the first item in the ⋮ menu, and there's a link to it on an empty shelf. It walks through every setup step in order:
  1. Add guides.
  2. Link Cocoon's folder.
  3. Link your artwork.
  4. Make WalkThor Cocoon's companion app.
  5. Turn on swipe to open.

  Each step shows a tick once it's done, or a button to do it right there. The page also explains how Now playing and the guide reader work, with tips.

## Changed
- **Tidier menu.** Performance check moved from the ⋮ menu to **About & licences → Diagnostics**, since it's only needed for tracking down slowdowns.
