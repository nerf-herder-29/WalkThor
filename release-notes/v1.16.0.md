WalkThor 1.16 is all about using as little memory and processing as possible while you play.

## Changed
- **Artwork index stays on disk.** If you linked a big media folder (like Cocoon's `downloaded_media`), WalkThor used to load an index of every image in it, often tens of thousands, into memory at start-up and keep it there. That index now stays in a compact file and is read only while matching artwork, then released. That means less memory in use all the time and a quicker start.
- **Cocoon's log is only read when it changes.** WalkThor used to re-read the end of the log every 3 seconds. Now it checks the file's size and modification time and skips reading when nothing has changed.
- **Smaller PDF page cache.** Capped at 24 MB, and the zoom lens renders at most 2400 px per page (down from 3000).
- **Leaner app.** The release build is now shrunk and optimised, so there's less code to load.

Your artwork index is converted to the new format automatically the first time it's needed. No rescan required.
