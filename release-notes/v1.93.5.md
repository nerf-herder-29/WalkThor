WalkThor 1.93.5

## Changed
- **The game is brought back to the front after your home app is paused, instead of tapped.** Android ranks visible apps for its memory killer partly by the order they came up, and the most recent ranks best. With your home app left alone, it was up before the game, so the game ranked better and your home app was closed first when memory ran out (the flashing). Pausing your home app starts Android's launcher after the game, so the launcher ranked better and the game was closed first. Taps on the game's screen only moved the controller, not that order. Now, once the launcher is up, WalkThor brings the game's own window back to the front through AYN's system helper, as if you'd switched back to it from recent apps, with nothing restarted. This happens 1.5 and 6 seconds after your home app is paused, and whenever a home app comes up on the bottom screen during the game. It never happens while memory is critical. The memory log notes each time.
