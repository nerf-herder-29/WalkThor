WalkThor 1.78.1 fixes switching on the WalkThor keyboard.

## Fixed
- **The "WalkThor keyboard" switch now turns on.** WalkThor was giving Android the keyboard's name in the wrong form, so Android didn't recognise it and the switch stayed off.
- If the keyboard can't be switched automatically, a message on screen now says so and tells you what to do in Android's keyboard settings.
