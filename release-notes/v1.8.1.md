WalkThor 1.8.1 fixes linking the Cocoon folder.

## Fixed
- **Link Cocoon folder… now works.** After you picked the folder, WalkThor stopped checking it before it finished, so nothing was saved and no message appeared. It now finishes and shows "Cocoon linked" (or tells you if the folder you picked doesn't have Cocoon's `launch_debug.log`).

## Set up
Library ⋮ → **Link Cocoon folder…** → choose your **Cocoon** folder (the one containing `launch_debug.log`). Then launch a game from Cocoon and swipe down from the top of the bottom screen.
