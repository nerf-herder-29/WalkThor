WalkThor 1.23.3 fixes games whose name includes words like "Hero" picking the wrong art.

## Fixed
- **The right art for games with art words in their names.** WalkThor tells a hero image from an icon or box art by the folder and file names. A game whose own name contains one of those words, such as *Guitar Hero*, could have its icon mistaken for a hero image and used as the Now playing background. WalkThor now ignores the game's own name when working out what kind of image it's looking at.
