WalkThor 1.85.3 fixes the controller lock. Changes since 1.85.0:

## Fixed
- **Locking the controller to either screen works, and switching between them does too.** WalkThor could say it couldn't find a screen. It only counted screens Android reported as on at that moment, and Android can briefly report one as off; the first attempt at a fix then left out the bottom screen altogether. WalkThor now tells the screens apart by size alone, whatever Android says about them being on, and remembers them. If it ever can't, Diagnostics lists the screens Android reported.
- **Moving the controller back to an app that shows the status bar works.** The tap that hands the controller back landed on the very top edge of the screen, which in an app showing Android's status bar (an app's main screen, rather than a full-screen game) is the status bar, and that doesn't move the controller. The tap now lands just below the status bar. This also helps handing the controller back to the game after using WalkThor.
