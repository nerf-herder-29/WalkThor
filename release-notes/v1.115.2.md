# WalkThor 1.115.2

## Fixes
- Going back to the Games tab no longer opens search by itself. Search opens only when you press the search button (or Select).
- Games for an emulator that can only start its games from its own home-screen shortcuts, like Banana Native, now start from your games. If no emulator can open the game's file, WalkThor uses the home-screen shortcut you added for the same game from that emulator. Play time and the game's guide still go with the game in your ROMs folder.
