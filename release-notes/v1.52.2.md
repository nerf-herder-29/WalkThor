WalkThor 1.52.2 saves a report when it stops responding.

## Fixed
- **A report when WalkThor stops responding.** When Android closes WalkThor because it stopped responding, WalkThor now saves what it was doing at that moment, like a crash report, to share from About & licences. It also no longer reopens itself after that kind of close, so it can't get stuck repeating it.
