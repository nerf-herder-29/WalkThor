WalkThor 1.55.0 reads Windows games from .pcgame files and adds Refresh list to the library.

## Changed
- **Windows games from .pcgame files.** In your ROMs folder's Windows folder, each .pcgame shortcut is now one game, named after the file, whether it sits in the Windows folder itself or one folder down. Folders no longer count as games there, unless the Windows folder has no .pcgame files at all, in which case it works as before.

## New
- **Refresh list.** At the bottom of the list down the library's left, Refresh list reads your ROMs folder again, so games you've added or removed show up without going into Settings.
