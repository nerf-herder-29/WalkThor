WalkThor 1.38 adds a Stats tab.

## New
- **Stats tab.** A fourth tab during a game shows:
  - **Top screen FPS**, live, with a graph of the last minute and the average and low. It counts how often the top screen changes using the same screen capture as Mirror (Android asks first), so it needs no root or extra apps. Nothing is recorded or saved.
  - **Battery:** power draw in watts and how long the battery lasts at that rate.
  - **Heat:** how close the Thor is to slowing down from heat, plus the battery temperature.
  - **Memory:** how much is free.
  - **CPU:** the fastest core's current speed (where Android allows reading it).
  - **This session's play time**, and, once WalkThor has watched a game for a few minutes, **how long that game usually lasts on a full charge**.
- The screen stays bright while the Stats tab is open, like Mirror and Face Buttons.

## Changed
- On narrower display settings, the Face Buttons tab is labelled "Buttons" so all four tabs fit.

## Also in this release
If you skipped earlier updates: WalkThor reopens itself if Android closes it mid-game (1.37), the tab bar is centred with HUD-style brackets (1.36), and dimming follows your Auto-dim settings (1.35.2).
