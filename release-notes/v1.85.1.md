WalkThor 1.85.1 fixes the controller lock. Changes since 1.85.0:

## Fixed
- **Locking the controller to the top screen after the bottom one works.** It could say it couldn't find the top screen, because WalkThor only counted screens Android reported as on at that moment, and Android can briefly report one as off. WalkThor now tells the screens apart by size and remembers them. If it ever can't, Diagnostics lists the screens Android reported.
