WalkThor 1.92.4

## Fixed
- **Games are no longer ranked behind WalkThor for Android's memory killer.** WalkThor keeps itself and your home app protected during games, ranked just behind the app in front. But Android doesn't always rank the game as the app in front while the bottom screen is in use. In a Banana Native crash it ranked the game 101, behind WalkThor and the home app at 50. This device's memory killer closes the heaviest app in the worst-ranked group first, so the game was closed while WalkThor survived. WalkThor now puts the game's on-screen processes first (rank 0, where the app in front normally sits) whenever it renews its own protection, and Keeper does the same every few seconds. The memory log notes the first time each game needed it.
- **The Ranks lines in the memory log now show up.** In 1.92.3 they never appeared. WalkThor now reads the ranks more simply, and if it still can't, the memory log says why once per game.
