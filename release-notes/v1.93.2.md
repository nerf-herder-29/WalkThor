WalkThor 1.93.2

## Fixed
- **The memory log is no longer wiped when Android restarts WalkThor through its black home screen.** If Android had closed WalkThor during a game, it could start WalkThor again just to show the black stand-in home screen. That screen's first note was written before WalkThor had read the existing log, so the log was replaced with that single line, and the game's history and its report were lost. New lines are now always added to what's already there.
