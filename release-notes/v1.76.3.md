WalkThor 1.76.3 brings back pressing Back twice to close all apps.

## New
- **Press Back twice to close all apps** is back, alongside the dock's X button. Switch it on in Settings → General → Access. Two presses within 0.4 seconds close every open app, the game included, and a short message on screen says what was closed. Both presses still act as Back.
- About → Diagnostics now lists each Back press WalkThor sees while this is on, so it's clear whether the button is reaching WalkThor.
