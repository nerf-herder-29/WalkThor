WalkThor 1.72.3 keeps shortcut games simple.

## Changed
- **Shortcut games aren't guessed any more.** For a game Cocoon starts from a shortcut (BananaNative games, for example), Cocoon doesn't say which game it is, so the drawer now just shows the app's name, with no game's artwork, and doesn't ask what you're playing. Before, it showed whichever game you'd last picked in that app. You can still use Change game on Now playing if you want a game's guide and art.
