WalkThor 1.92.7

## Fixed
- **The game is kept as Android's app in front when a home app starts on the bottom screen.** Android gives its "app in front" spot to whichever screen an app last started on. That spot also decides who the memory killer closes last. When your stand-in home app starts on the bottom screen during a game (WalkThor pausing your home app, or Android restarting it after closing it for memory), the home app takes that spot. The game then drops behind the bottom screen's apps, and the memory killer closes it first. A moment after a home app comes up on the bottom screen during a game, WalkThor now taps the very top edge of the game's screen to put the game back in front, the same way the controller lock does. The memory log notes it once per game. Apps you open on the bottom screen yourself are left alone.

## Removed
- **WalkThor no longer tries to set memory-killer ranks itself.** Writing ranks directly doesn't change who the memory killer closes, because it goes by the ranks Android gives it. The logs showed WalkThor still "ranked 100" when closed, right after being set to 50. Keeper no longer sends those commands every few seconds during games. The Ranks lines in the memory log still show how Android ranks things.
