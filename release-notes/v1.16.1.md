WalkThor 1.16.1 takes the load off games right when they start.

## Changed
- **Artwork lookups barely touch the CPU anymore.** When a game without a guide launched, WalkThor broke down the file name of every image in your media folder to find the game's artwork. That's a full-speed burst right while the game was loading its title screen. Now:
  - those words are worked out once, when the folder is indexed, and saved with the index,
  - images that share no word with the game's name are skipped straight away,
  - the result is remembered, so swiping in again doesn't repeat the search.
- **WalkThor's background work runs at the lowest priority.** Artwork matching and suggestions run on a background thread that Android serves only when nothing more important, like your game, needs the CPU.
- **Shorter dim fade.** The screen now dims over 0.4 seconds instead of 1.2, so there are fewer frames to draw on the bottom screen.

Your artwork index is upgraded automatically in the background the next time WalkThor starts.
