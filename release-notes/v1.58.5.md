WalkThor 1.58.5 stops WalkThor's comeback from taking the game down with it, and fixes a crash when captions or clips stop.

## Fixed
- **Games could crash when WalkThor reopened itself.** When a heavy game runs short of memory, Android sometimes closes WalkThor to make room. WalkThor used to reopen itself a split second later, while the game still needed that memory, which could get the game closed too. Now it waits until the device has memory to spare again (at least 10 seconds, usually longer) before reopening. If memory stays low for 3 minutes, it stays closed and you can swipe down to open it. It also reopens at most 3 times in 10 minutes (it was 10).

- **WalkThor could crash when Captions or clips stopped.** Stopping them could free Android's sound capture while it was still waiting for the game to make a sound (common when a game goes quiet), which crashed WalkThor. They now stop the capture, let it finish, and only then free it.

## New
- **Recent closes, in About & licences → Diagnostics.** Each time WalkThor's app closed, why (closed by Android for memory, a crash, not responding, closed by you), how much memory it was using, and what it was doing just before (a game running, screen capture, clips, captions). It stays on your device; "Share recent closes" sends it as text if you want to report a problem.
- **Settings → General → "Reopen during a game".** Switch it off if you'd rather WalkThor stay closed after Android closes it; swipe down to bring it back when you want it.

## Improved
- WalkThor no longer asks Android for extra memory headroom.
