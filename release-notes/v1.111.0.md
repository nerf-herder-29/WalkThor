# WalkThor 1.111.0

## Every emulator WalkThor can start
- WalkThor now knows how to start games in 105 Android emulators, using the launch rules from ES-DE Frontend. That covers standalone emulators such as DuckStation, NetherSX2, AetherSX2, Play!, PPSSPP, Azahar, Citra, Lime3DS, Mandarine, melonDS, DraStic, Cemu, Vita3K, aPS3e, ARMSX3, aX360e, Flycast, Redream, Yaba Sanshiro, My Boy!, Pizza Boy, Skyline, Kenji-NX, Winlator, GameHub Lite, MAME4droid, ScummVM and the Emu family (MD.emu, GBA.emu and the rest).
- RetroArch works too, with each of its cores as its own choice (for example "RetroArch: mGBA" or "RetroArch: Beetle PSX HW").
- Your ROMs folder is read again by itself so the new systems show up. WalkThor now recognises about 130 more system folders, using ES-DE's folder names (c64, msx, atari7800, fds, naomi, zxspectrum, scummvm, ports and many more).
- In Settings > Emulators, each system's "Starting games" list shows every emulator you have that can start its games, and it scrolls when the list is long. When you leave it to WalkThor, it picks WalkThor's tested emulators first, then other standalone emulators, then apps whose names match the system, then RetroArch.
- If an emulator needs something a game doesn't have (for example a .ps3 file with the game's serial), WalkThor moves on to the next emulator, and the game report says why.
- Apps from that list now count as emulators for the drawer and play time without ticking them by hand.
- The new systems get their own ring colours and labels, and art from libretro's thumbnails where libretro has them.
- Pictures from your art folder are matched again so the new systems pick up their art.
