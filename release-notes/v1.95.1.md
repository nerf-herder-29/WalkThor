WalkThor 1.95.1

## Fixed
- **The games screen is the right way round.** The covers now always go on the bottom screen and the chosen game on the top. If WalkThor was open on the top screen, it moves itself down first.
- **No more "WalkThor isn't responding".** The top-screen picture wasn't allowed to take the controller. When Android gave it the controller anyway, your button presses had nowhere to go, and Android reported WalkThor as not responding. The top screen now takes button presses and passes them on to your games.
- **Starting games.** Games now start on the top screen explicitly. If an emulator won't open the game the first way, WalkThor tries handing it the game's file the ordinary way. If a game still won't start, a message says why for each emulator tried, and the same goes into the memory log sent with game reports.

## New
- **WalkThor can be your home app.** Pick it in Android's Settings → Apps → Default apps → Home app. Home then shows the top-screen picture, with your games on the bottom screen. Back does nothing there, the way it works on a home screen.
