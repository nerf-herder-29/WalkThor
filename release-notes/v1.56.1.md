WalkThor 1.56.1 also reads Windows games from .steam and .steamappid files.

## Changed
- **.steam and .steamappid files count as Windows games too.** In your ROMs folder's Windows folder, each .pcgame, .steam or .steamappid shortcut is one game, so you can mix them. A game with more than one of these files shows once. Tap Refresh list in the library after updating.
