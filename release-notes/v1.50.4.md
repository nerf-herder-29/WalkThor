WalkThor 1.50.4 keeps its accessibility access with busy frontends like iiSU, and opens by itself again when you launch from them.

## Fixed
- **WalkThor no longer loses its accessibility access.** With "Recognise the game you pick" on, WalkThor read your frontend's whole screen each time it changed. An animated frontend such as iiSU changes constantly, and on both screens, so that reading could hold the accessibility service up long enough for Android to stop it and switch it off. Reading now happens in the background, at most twice a second, never piles up, and reads fewer items per pass. A problem with any single event can no longer take the service down.
- **Opens by itself again with iiSU.** In 1.50.3, WalkThor stopped opening on its own when the frontend that launched the game (such as iiSU) still had its own screen on the bottom display, because jumping in front of it straight away made the frontend close the game. Now WalkThor waits five seconds for the game to finish starting, then opens on it, as long as the game is still running.
