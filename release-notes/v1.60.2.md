WalkThor 1.60.2 makes the AYN button reliable during games.

## Fixed
- **The AYN button stopped reopening WalkThor during a game.** When WalkThor opened as an app, Cocoon brought its own screen forward on the top screen, so WalkThor thought the game had ended and left the AYN button to AYN's drawer. WalkThor now knows the game is still running underneath, and also checks the launch log.

## Changed
- **Open when an emulator starts** opens WalkThor as the drawer when the AYN button is set to open WalkThor, so your frontend stays put.
- If the drawer opens but doesn't appear within two seconds, WalkThor takes it away and opens as an app instead (Diagnostics says so).
- Diagnostics lists the last few AYN button presses, what WalkThor saw (drawer up, app up, a game running and why) and what it did. "Share result" includes them.
