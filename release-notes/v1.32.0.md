WalkThor 1.32 keeps Now playing steady when the screen dims.

## Changed
- **Nothing moves when the screen dims or wakes.** Now playing and the dimmed screen now share one layout: the game's name and emulator, with the Open guide (or Add guide), Mirror and Face Buttons buttons under them, all centred, in exactly the same place either way.
- **Add guide from the dimmed screen.** When a game has no guide yet, the dimmed screen offers Add guide where Open guide would be.
- **Other guide / From my shelf** is a small link under the buttons on the awake screen.
- **No more blur.** The game's art now fills the awake screen sharp, with gentle shading so the text stays readable.
