WalkThor 1.91.8

## Changed
- **A simpler wait while a game loads.** At 10 seconds, WalkThor checks memory. If free memory has stopped falling (less than 150 MB in the last 5 seconds) and at least 2.5 GB is free, WalkThor comes up. If not, it checks again every 5 seconds, for up to 90 seconds. It no longer waits for Android's memory pressure reading to settle, which could hold it back long after a game had loaded. Tapping the black screen still brings WalkThor up straight away.
