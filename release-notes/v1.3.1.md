WalkThor 1.3.1 fixes updating.

## Fixed
- **Updates now install over the previous version.** Earlier releases were each signed with a different temporary key, so Android refused to update them ("conflicting package"). From this release on, every WalkThor APK is signed with the same permanent key.

## One last reinstall
Because your installed copy has an old key, uninstall WalkThor once and install this version. Every release after this one will install as a normal update and keep your shelf, covers and reading positions.
