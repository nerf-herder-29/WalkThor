WalkThor 1.22.3 finds the game's window more reliably when handing it back top priority.

## Fixed
- **Finds the game's window.** WalkThor now looks for the game on every screen except its own, rather than on just one, and prefers the window Android last had focused.
- **A second way in.** Some emulators don't answer when WalkThor reaches for their window. WalkThor now brings the game's task forward instead, which also doesn't pause the game.
- **Keeps trying.** If the first try fails, WalkThor tries again a few times, a second and a half apart, using both ways.

## Performance check
- The **Hand-back** line now says more when it can't find the game, including which kinds of windows it did see, to help track down the cause.
