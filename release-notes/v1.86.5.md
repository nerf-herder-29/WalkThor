WalkThor 1.86.5 helps stop the bottom screen flashing during heavy games, without costing you the game. Changes since 1.86.1:

## Fixed
- **Fewer crash loops on the bottom screen.** When a game suddenly needs a lot of memory, Android can close your home app and WalkThor, and they kept being closed as they started again: the white flashing on the bottom screen. WalkThor already ranked them just below the game for Android's memory killer, but WalkThor was often closed in the same burst, and while it was gone nothing kept the home app protected. Now WalkThor's small second process, Keeper, renews the protection once a second during games too. It needs Force SELinux off, as before.

## New
- **The game comes first.** When memory gets critical during a game (free memory under 1.5 GB, or Android's most serious memory warning), WalkThor and Keeper stop protecting the bottom screen's apps and WalkThor lets go of what it can, so Android closes those rather than your game. Until memory recovers, nothing at all is run through AYN's system helper, since each command is a strain of its own at that moment. The protection comes back once memory has recovered for 20 seconds, and the memory log notes each time.
- **Keeper's status in Diagnostics.** About & licences → Diagnostics → Memory during games shows whether Keeper is running, whether it can use AYN's system helper, and how it's ranking the bottom screen's apps. Lines starting "Keeper:" in the memory log show what it changed while WalkThor was closed.

## Removed
- **Darkening the bottom screen at critical moments,** tried in the 1.86.4 test build. Changing the brightness meant starting a program through the system helper at the worst possible moment, and it could freeze the whole device. If 1.86.4 left your bottom screen dim, WalkThor puts the brightness back.
