# WalkThor 1.115.0

## Updates on your games screen
- Updates is now a tab on the main screen, after Games and Apps, so you can update your emulators without opening the drawer. It's the same updater as in the drawer, with the same cards, release notes and installs.
- While the Updates tab is open, the top screen sums things up: how many updates are waiting, when WalkThor last checked, and each emulator with its installed version (and the new one, if there is one).
- With this many tabs, the tab row now scrolls. Each tab keeps a comfortable size so no names are squeezed, and the open tab slides into view as you move with L1 and R1. A soft fade shows when there are more tabs off to one side.
