WalkThor 1.23.2 uses only scene art for the Now playing background.

## Changed
- **Backgrounds are scene art only.** The Now playing background now comes only from a game's hero, fan art, screenshot or title-screen image. Box art and icons have the game's logo printed on them, which clashed with the logo WalkThor already shows, so they're no longer used as backgrounds. A game with no scene art gets a plain black background, with its logo or title and the guide buttons as usual.
