WalkThor 1.15.2 uses much less memory, to play nicer with games and apps like Wayfinder running alongside it.

## Fixed
- **Less memory pressure on other apps.** WalkThor used to ask Android for an enlarged memory allowance and kept big image caches. Because Android protects a visible app like WalkThor ahead of background services, a short-on-memory Thor could close Wayfinder (its FPS overlay would vanish and come back) or even the game to make room. WalkThor now:
  - uses Android's normal memory allowance,
  - keeps a much smaller cache of cover images,
  - lets go of rendered PDF pages and its PDF search index whenever Android reports memory is running low, or when WalkThor goes into the background. They're rebuilt on demand.
