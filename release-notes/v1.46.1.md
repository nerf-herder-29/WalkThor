WalkThor 1.46.1 fixes a crash when memory runs low.

## Fixed
- **Crash while a heavy game loads.** When Android warned that memory was running low (or a new game started, or the screen dimmed fully), WalkThor frees the PDF pages it has cached. If Android reclaimed one of those pages at the same instant, WalkThor could crash. That's exactly when big games are loading, so this was the most likely source of WalkThor closing mid-launch. It now handles this safely.
