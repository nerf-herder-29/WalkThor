WalkThor 1.105.0

## New
- **A stronger picture downloader.** Settings → Guides → Games screen → Art site accounts takes a SteamGridDB API key (free) and, if you like, your ScreenScraper account. Download missing pictures then gets each game's square icon, hero and logo from SteamGridDB first, including Switch and PC games (PC games by their Steam id when they have one). It fills any gaps from ScreenScraper (box art, fan art, wheel logos), then from the free libretro collection and Steam. If a site refuses the key or hits its daily limit, the result says so. Keys you entered for WalkThor's old scraper are picked up again.

## Changed
- **A black bottom screen during games.** While a game plays, the bottom screen is now plain black. Tap it for Home and the tabs. It stays as before if you have the drawer come up when a game starts (Settings → Emulators), or the game uses both screens.

Tip: to swap downloaded screenshots for SteamGridDB heroes, press Delete downloads, then Download.
