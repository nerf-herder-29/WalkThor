WalkThor 1.63.0: hold the AYN button for AYN's own drawer.

## New
- **Hold the AYN button to open AYN's drawer.** With *AYN button opens WalkThor* on, a tap still slides WalkThor up (and away); holding the button for about half a second opens AYN's own drawer instead, so you don't lose it. Diagnostics notes how WalkThor opened it (or why it couldn't).
