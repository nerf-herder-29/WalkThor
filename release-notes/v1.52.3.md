WalkThor 1.52.3 fixes "WalkThor isn't responding" and stray input reaching Cocoon.

## Fixed
- **No more "WalkThor isn't responding", and no more controller input going to Cocoon.** During a game, WalkThor lets the game keep the controller by not taking input focus. It decided a game was running from Cocoon's launch log alone, so back in Cocoon after playing it still refused focus: your button presses went to Cocoon (moving it on its own), and when Android tried to give input to WalkThor, it found nothing to give it to and reported WalkThor as not responding. Now WalkThor only steps aside when a game is actually in front on the other screen. Without accessibility access it can't see that, so it goes by the log as before.
