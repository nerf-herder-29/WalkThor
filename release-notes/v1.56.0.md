WalkThor 1.56.0 works with ES-DE.

## New
- **ES-DE support.** Link ES-DE's folder in Settings → ES-DE, and WalkThor knows each game you start from ES-DE, the same way it does with Cocoon: Now playing, the right guide opening by itself, the game's art, play time and Multi view all work.
  - In ES-DE, open Main menu → Other settings and turn on **Custom Event Scripts** and **Debug Mode**. ES-DE then writes each launch to its own log, `ES-DE/logs/es_log.txt`, which is what WalkThor reads (only that file; nothing is changed).
  - ES-DE also logs when you return from a game, so WalkThor knows exactly when you've stopped playing.
  - To have WalkThor open by itself when a game starts, turn on Settings → Emulators → Open when an emulator starts.
- You can link both Cocoon and ES-DE; WalkThor goes by whichever launched a game most recently.
- **ES-DE's artwork works too.** Link ES-DE's `downloaded_media` folder in Settings → Artwork (now "Cocoon / ES-DE artwork") and WalkThor uses its covers, screenshots, fan art and marquees, the same as Cocoon's media. Flat box art is preferred over 3D boxes, and cartridge and disc photos are never used as covers.
