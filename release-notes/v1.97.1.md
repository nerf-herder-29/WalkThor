WalkThor 1.97.1

## Changed
- **All your games on one screen.** The games screen no longer has the All, Recent, Favorites and system tabs: every game is in one grid, A to Z. L1 and R1 now jump to the previous or next letter.

## Fixed
- **Cocoon's artwork.** Cocoon calls its covers "icons", and WalkThor wasn't looking for those. It now reads icon pictures as covers, and matches pictures named with or without the game file's ending. The Art folder row now always says how many pictures it found, gives a few example paths, and says why if the folder couldn't be read.
- **Downloading pictures.** Downloads no longer depend on how the server labels its pictures; WalkThor checks the file itself. It also asks the way a browser does. Games whose file names differ from the collection's (for example "Pokemon Emerald" against "Pokemon - Emerald Version") are now matched by their words. If nothing comes down, the result now says what went wrong first.
- **Screens going missing.** The top screen no longer closes when something covers it for a moment, such as the screen turning off. It now closes only when a game starts. With WalkThor as your home app, Android no longer puts its own launcher over your games on the bottom screen: WalkThor is now the bottom screen's home too. If Android opens a second WalkThor there, the older one closes.
