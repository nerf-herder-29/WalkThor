WalkThor 1.26 swaps the gold accents for a calmer grey look.

## Changed
- **Grey instead of gold.** Buttons, selected options and the done ticks are now a medium-dark grey with light text, and the small headings, icons and accents that were gold are a medium grey. This covers the shelf, Now playing, the dimmed screen, the reader, settings, the setup page and the boot animation. Search highlights on guide pages stay yellow, so matches are easy to spot.
