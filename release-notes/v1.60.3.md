WalkThor 1.60.3 fixes the AYN button during games when Open when an emulator starts is off.

## Fixed
- **The AYN button opened AYN's drawer during a game** unless *Open when an emulator starts* was on. Android was merging quick back-to-back app switches, so when Cocoon updated its own screen right after starting a game, WalkThor never saw the game come to the front. With the AYN button set to open WalkThor, every switch now gets through.
