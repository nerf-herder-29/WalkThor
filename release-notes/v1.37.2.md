WalkThor 1.37.2 comes back even faster after a heavy game pushes it out.

## Changed
- **Reopens right away.** When Android closes WalkThor to free memory during a game, WalkThor reopens as soon as Android lets it restart, with no extra wait.
- **No startup animation when it comes back**, so you're straight back on Now playing.
- **The game gets its priority back sooner** after a reopen (about 1 second instead of 2.5).
- **More tries.** It reopens up to 10 times in 10 minutes before staying closed.

## Also in this release
If you skipped 1.37.0 or 1.37.1: WalkThor reopens itself on the bottom screen if Android closes it mid-game, frees memory when a game starts, and Diagnostics shows when this happened.
