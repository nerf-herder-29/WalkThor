# WalkThor 1.112.0

## A different emulator for one game
- Press X on a game (or hold it) and choose "Start it in…" to pick the emulator for that game alone. The menu shows which emulator it starts in now. "The same as other games" puts it back on its system's emulator from Settings > Emulators.

## The guide for the game you started
- If WalkThor opens on the Guide tab while you play, it now opens the guide for the game you started from your games. If that game has no guide yet, you get the list of guides to pick from, not the last guide you read for another game.
- Games started from somewhere else work as before.

## Tidier settings
- Screen: removed "Always open on bottom screen" and "Move to the other screen". WalkThor's screens now always open on the bottom, with your games' spotlight on the top screen, so these only got in the way. If you had "Always open on bottom screen" switched off, it's back on.
- Library: the hints for hiding a game and adding a guide now say exactly where to go (press X on a game, or hold it). The Sounds description matches the softer sounds.
- Emulators: a note explains how to start one game in a different emulator from the rest of its system.
