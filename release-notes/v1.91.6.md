WalkThor 1.91.6

## Fixed
- **Your home app is no longer brought up over a game that's still running.** When Android's memory killer closed the stand-in launcher mid-game and Android started it again, its window appearing on the top screen looked to WalkThor like you'd left the game. WalkThor then put Cocoon back and brought it up over the game. The game was pushed to the background, which looked like a crash, and it could later be closed there for memory. Now WalkThor asks Android which app is really in front before putting your home app back. If it's still the game, nothing changes, and the memory log says so.
