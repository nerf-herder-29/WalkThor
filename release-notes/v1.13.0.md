WalkThor 1.13 adds a boot screen and fixes WalkThor sometimes opening already dimmed.

## New
- **Boot screen.** When WalkThor opens, the book from its icon unfolds and the magnifier sweeps across the pages while WalkThor checks Cocoon's launch log. If it finds the game you're playing, it shows **Now playing · <game>** and fades straight into that guide's opening animation. You won't see the library flash by first. This helps most when WalkThor is set as a game's **companion app** in Cocoon. If Cocoon hasn't written the launch yet, WalkThor keeps looking for a moment before going to your library. Tap to skip.
- The boot screen doesn't play when you move WalkThor to the other screen, or when another app opens a file in it.

## Fixed
- WalkThor no longer opens already dimmed. It used to happen when WalkThor was opened again after sitting unused in the background. The auto-dim timer now restarts every time WalkThor comes to the front.
