WalkThor 1.76.4 makes "close all apps" actually close the game.

## Fixed
- **The game in front is closed too.** Close all apps now starts with whatever is in front on each screen, then your recent and running apps. After asking Android to stop each one, it checks that the app really stopped, and ends it directly if not.
- **The message names what was closed** ("Closed Dolphin, Chrome"), and says so if an app couldn't be closed, instead of only giving a count. About → Diagnostics has the full detail from the last time.
