# WalkThor 1.119.2

## Joy-Con joining: it starts now
- "Join them" never actually started the joining program: the command that starts it was too long for the Thor's system helper, which cut it off. WalkThor now writes that command to a small script in its own files and has the helper run the script.
- The Controllers screen no longer reports the joining program as running when it isn't. Its check was finding itself.
