WalkThor 1.75.0 comes back reliably when Android closes it, and can't leave the bottom screen stuck off.

## Fixed
- **The bottom screen can't get stuck off.** "Bottom screen off" no longer turns the screen's brightness down; it only covers the screen in black (on this OLED panel, black pixels aren't lit). So if WalkThor stops for any reason, the cover goes with it and the screen is simply on again. When WalkThor comes back, it puts the cover back if the screen was off. If an older version left your bottom screen's brightness all the way down, this puts it back up once.
- **WalkThor comes back faster after Android closes it.** A tiny keeper process now notices the moment WalkThor is closed and starts it again, with a standing alarm behind it in case the keeper is closed too. Before, WalkThor waited for Android to restart it, which could take a long time.
- **The drawer always comes back if it was up.** WalkThor now remembers that the drawer was up, rather than guessing from why Android says it closed (many low-memory closes weren't recognised, so it stayed closed). It waits for a little spare memory for at most 10 seconds, then comes back regardless, instead of giving up after 90 seconds. It can come back 6 times in 10 minutes, up from 3.
- **Bottom screen off during games is steadier.** It waits about a second for things to settle before turning the screen off or on, so it doesn't flash as a game starts or closes.

## Changed
- The setting "Reopen during a game" is now "Bring WalkThor back".
