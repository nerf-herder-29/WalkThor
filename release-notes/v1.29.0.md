WalkThor 1.29 adds Controls: what each original button is on the Thor.

## New
- **Controls.** When a game says "Press △" or "Hold C-Up", glance at the bottom screen. Controls shows a diagram of the controller for the system you're playing, with every button labelled with the Thor button that does it.
  - Open it from **Controls** on Now playing or the dimmed screen.
  - WalkThor picks the layout from the emulator, for example Dolphin → GameCube, AetherSX2/NetherSX2 → PlayStation, PPSSPP → PSP, aX360e → Xbox 360, Eden and similar → Switch, Mupen or RetroArch with an N64 file → N64. There are also SNES, NES, Genesis, GBA and DS/3DS layouts. **Layout** changes it, and the choice is remembered for that emulator.
  - Face buttons are shown by position: a small diamond marks which of the Thor's four face buttons it is, so it's right whatever the labels say.
  - Mappings start from each emulator's usual defaults. If yours differ, tap a button and pick (or press) the Thor button that does it. Corrections are remembered per emulator.
- **Show presses (optional).** Turn it on to see buttons light up as you press them, with a line saying what you pressed ("You pressed R1 → Z"). You're asked first. While this screen is open with the option on, WalkThor's accessibility service sees each button press on its way to the game and passes it straight on. Nothing is recorded or kept. Analog sticks can't be shown, because Android doesn't share stick movement with accessibility services.
  - Android may need you to switch WalkThor off and on in Accessibility settings once before Show presses works. The screen will tell you if so.

## Design note
- The diagrams are deliberately generic: a plain body shape of WalkThor's own, with buttons placed roughly where each system has them and named the usual way. No logos, brand colours or traced controller outlines.
