# WalkThor 1.123.0

## Sleep from the controller
- New shortcut action: "Sleep (screens off)". It puts the Thor to sleep like a short press of the power button.
- New shortcut: Back + Select. It's set to Sleep unless you change it in Settings › Shortcuts. Hold Back and press Select, anywhere, in a game or not.
- As with the other Back combinations, Back on its own still works as usual. It goes through when you let go of it without pressing anything else.
