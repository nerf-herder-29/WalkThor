WalkThor 1.74.1 fixes the top screen's FPS.

## Fixed
- **The FPS no longer vanishes.** Putting the FPS on the top screen made WalkThor think the game had gone, so it took the FPS away again. A missed reading now doesn't hide it either, and if it can't be shown WalkThor waits before trying again instead of trying every second.

## Changed
- **Much more see-through.** The FPS pill is now barely-there glass with white text and a soft shadow, so it reads over light and dark scenes.
