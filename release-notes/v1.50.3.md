WalkThor 1.50.3 stops dual-screen frontends like iiSU from closing your game.

## Fixed
- **Games launched from iiSU no longer close straight away.** iiSU keeps its own screen on the bottom display while a game runs. With "Open when an emulator starts" on, WalkThor jumped in front of it, and iiSU closed the game and came back. Now, when the frontend that launched the game is still showing on the bottom screen, WalkThor stays out of the way. It still knows which game you started, so swiping WalkThor open goes straight to it.
- **What shows on the bottom screen no longer ends the game.** A frontend's second screen appearing there was being taken as you leaving the game.
